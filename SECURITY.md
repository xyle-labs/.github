# Security policy

## Report privately

Use **Security → Report a vulnerability** in the affected repository. Its own
security policy takes precedence over this organization default.

- [Xyle Trace](https://github.com/xyle-labs/xyle-trace/security/advisories/new)
- [Xyle Motion](https://github.com/xyle-labs/xyle-motion/security/advisories/new)
- [Organization profile and shared files](https://github.com/xyle-labs/.github/security/advisories/new)

Include the affected version or commit, expected impact and a minimal synthetic
reproduction. Never include live credentials, confidential datasets or personal
recordings. Keep vulnerability details out of public issues and pull requests
until maintainers have coordinated disclosure.

## Supported versions

Support and release policies are defined by each project. Fixes to these shared
organization files target the default branch. No response-time guarantee is made.
