# Xyle Labs

Local-first tools for AI-assisted work. Keep the evidence behind your results
inspectable, and turn your project's knowledge into editable explainers.

## Projects

### [Xyle Trace](https://github.com/xyle-labs/xyle-trace)

**Where does this number come from?** Record sources, snapshots, transformations
and evidence-backed claims as a coding agent works. Query the local provenance
graph and replay retained executions through a Python toolkit, CLI and MCP server.

[Get started](https://github.com/xyle-labs/xyle-trace/blob/main/docs/quickstart.md)
· [Documentation](https://github.com/xyle-labs/xyle-trace#readme)
· [Issues](https://github.com/xyle-labs/xyle-trace/issues)

### [Xyle Motion](https://github.com/xyle-labs/xyle-motion)

**Explain what your project knows.** Create editable explainer videos from YAML
with a shared renderer, reusable artwork and local recorded narration. One CLI
and one coding-agent skill, used inside the project that owns the knowledge.

Public development preview; installation currently uses a locally packed build.

[Get started](https://github.com/xyle-labs/xyle-motion#readme)
· [Examples](https://github.com/xyle-labs/xyle-motion/tree/main/examples)
· [Issues](https://github.com/xyle-labs/xyle-motion/issues)

## Working in the open

We build tools with local data, inspectable files and deterministic cores.
Questions, bug reports and contributions belong in the relevant project; start
with its README and contribution guide. Use synthetic examples in public reports.
Report vulnerabilities privately through the project's Security tab.

Each project has its own license: Xyle Trace uses Apache-2.0; Xyle Motion's
original code and assets use MIT, with third-party terms in its NOTICE.md.
